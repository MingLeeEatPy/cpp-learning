# C++ Learning

记录我的 C / C++ 与算法竞赛学习过程。

这个仓库用于长期记录从 **C 语言基础 → C++ → 数据结构与算法 → ACM/ICPC 算法竞赛** 的学习过程，包括语法练习、示例代码、算法实现以及后续的刷题记录。

## 1. C Language Basics

`C-Basics/`

当前学习阶段。

主要通过编写简单的示例代码掌握 C 语言的基础语法，并理解程序设计中的一些底层概念，为后续学习 C++ 打基础。

计划包括：

- Basic syntax
- Variables & data types
- Input & output
- Operators
- Conditional statements
- Loops
- Functions
- Arrays & strings
- Pointers
- Structs
- Basic memory concepts

C 语言在这个仓库中主要作为 **编程基础与底层概念的学习阶段**。完成基础学习后，将逐步转向 C++。

## 2. C++ Basics

`Cpp-Basics/`

完成 C 语言基础后，开始系统学习 C++。

计划包括：

- C++ basic syntax
- References
- Classes & objects
- OOP
- Templates
- STL
- `vector`
- `string`
- `map`
- `set`
- `stack`
- `queue`
- Iterators
- Standard algorithms

这一阶段的重点不仅是学习 C++ 语法，也会逐渐转向 **算法竞赛常用的 C++ 编程方式**。

## 3. Algorithms & ACM

`Algorithms/`

在掌握 C++ 基础和 STL 后，开始系统学习数据结构与算法，并进行 ACM / ICPC 方向的训练。

计划包括：

- Complexity analysis
- Sorting & searching
- Recursion
- Binary search
- Prefix sum
- Two pointers
- Stack & queue
- Linked list
- Trees
- Graph algorithms
- Greedy algorithms
- Dynamic programming
- Number theory
- String algorithms

后续也会在这里记录：

- Problem solutions
- Algorithm templates
- Contest notes
- Mistakes & lessons learned
